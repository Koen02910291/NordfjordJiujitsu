# Jiu-Jitsu Nordfjord website

Statisk, mobilvennleg og tospråkleg nettside for GitHub Pages.

## Struktur
- `index.html`: nynorsk startside
- `en/index.html`: English start page
- `personvern/index.html`: personvern
- `en/privacy/index.html`: privacy
- `assets/`: shared CSS, JavaScript and images

## Før publisering
1. Erstatt alle `[INVULLEN...]` / `[ENTER...]`-felt.
2. Erstatt `[INVULLEN-DOMENE]` i HTML, `robots.txt` og `sitemap.xml` med det endelege domenet.
3. Kontroller offisielt klubbnamn, organisasjonsnummer, kontaktadresse og behandlingsansvarleg.
4. Få personvernteksten kontrollert før publisering.
5. Kontroller publiseringsrettar og samtykke for alle bilete.
6. Oppdater sitemap når sider eller URL-ar blir endra.

## Juridisk og teknisk kontrolliste
- Eksterne tenester: Google Fonts, Instagram-lenkje, Facebook-lenkje og lenkjer til Hamna Treningssenter.
- Third-party scripts: ingen.
- Analytics, annonsepikslar og marknadsføringscookies: ingen.
- Skjema: ingen. Kontakt skjer via e-post- og telefonlenkjer.
- localStorage: lagrar `preferredLanguage` for språkval til brukaren slettar nettlesardata.
- Innebygde kart, videoar og sosiale medium: ingen.
- Kontroller om henting av Google Fonts skal erstattast med lokalt lagra fontfiler for betre personvern.
- Kontroller at språkval og localStorage er tilstrekkeleg dokumentert og at cookiebanner ikkje er nødvendig for endeleg løysing.
- Ingen passord, API-nøklar, innsendingar eller andre personopplysningar skal leggjast i GitHub-repositoriet.

## Lokal test
Opne `index.html` direkte, eller køyr ein lokal statisk server i prosjektmappa.
